## 实际需求：改主题，但只调整一个实例

整体主题使用绿色；某个按钮改为圆角胶囊；一处输入框加边框；某个下拉弹层局部改底色。组件库部分只讨论样式入口，不展开通用业务 API。

```tsx title="StyledControls.tsx · Ant Design 6"
import { Button, ConfigProvider, Input, Select } from 'antd'
import styles from './controls.module.css'
export function StyledControls() {
  return <ConfigProvider theme={{
    token: { colorPrimary: '#568275', borderRadius: 8 },
    components: { Button: { fontWeight: 600 } },
  }}>
    <section className={styles.zone}>
      <Button type="primary">主题按钮</Button>
      <Button type="primary" styles={{ root: { borderRadius: 999 } }}>仅这个按钮</Button>
      <Input className={styles.oneInput} placeholder="局部输入框" />
      <Select defaultValue="notebook" options={[{ value: 'notebook', label: '笔记本' }]}
        classNames={{ popup: { root: styles.productPopup } }} />
    </section>
  </ConfigProvider>
}
```

```css title="controls.module.css"
.zone { display: grid; gap: 12px; }
.oneInput { border-width: 2px; }
/* 通过公开 popup root 类直接限定，不要求弹层位于 zone 下。 */
.productPopup { background: #f2f8f5; }
/* 确需配合库类时，限制全局例外的外层范围。 */
.zone :global(.ant-input:hover) { border-color: #568275; }
```

styles/classNames 的语义键按组件和版本核对，不能把一个组件的 root/popup 名称复制到所有组件。Ant Design 5 教程中的旧属性不一定是 6.x 推荐入口。

## 作用域与选择器边界

Vue scoped 的 deep 允许选择器穿过子组件的作用域属性边界；它不会把已经 Teleport 到 body 的节点搬回原祖先。因此 `.theme-zone :deep(.popup)` 仍要求实际 DOM 存在 theme-zone 祖先。直接给弹层公开类，再用有边界的全局规则，通常更明确。

React CSS Modules 的 :global 只是选择器编译例外，`.zone :global(.ant-select-dropdown)` 仍无法匹配位于 body 的独立下拉层。避免深层结构选择器、内部生成 hash 类名和覆盖所有 `.ant-*`/`.el-*` 的规则，它们对升级敏感。

React Portal 保留 React 树的 Context 和事件传播关系，CSS 却由实际 DOM 决定。Ant Design ConfigProvider 的逻辑主题上下文可跨 Portal；自定义 CSS 变量若仅在局部 DOM 上定义，仍须单独检查继承。

部分组件可配置弹层容器，例如 Ant Design Select 的 getPopupContainer、Element Plus Select 的 teleported 等公开配置。改变容器前要检查 overflow 裁剪、滚动定位与层级，不应把“全部挂回父节点”当通用修复。

## 优先级与排查顺序

1. 说明目标是全局主题、某类组件还是单实例；检查 token、CSS 变量、class/style 与语义入口。
2. 在开发者工具中定位真实节点，确认规则是否匹配；没匹配先修作用域或挂载位置。
3. 查看最终计算规则和变量来源，比较选择器权重、层叠层、导入顺序、内联规则。
4. 只有确有必要时用 important，说明它要覆盖哪条规则，并限定到本实例。加 important 不能修复匹配不到节点的问题。

层叠层的顺序可能先于同一来源内的选择器权重，important 还会改变层叠优先关系。不要只按选择器字符串长短判断最终结果。
