## 概念速查

| Vue 概念                | React 中可比较的内容                 | 关键区别                                 |
| ----------------------- | ------------------------------------ | ---------------------------------------- |
| ref / reactive          | useState / useReducer                | 响应式容器与快照、更新队列不同           |
| 模板 ref                | DOM ref / useRef                     | 与 Vue 数据 ref 分清用途                 |
| computed                | 直接计算 / useMemo                   | 先直接计算，再按需优化                   |
| watch / watchEffect     | Effect 或事件                        | 先判断外部同步需求；React 不自动追踪属性 |
| onMounted / onUnmounted | Effect setup / cleanup               | 依赖变化也会清理重建                     |
| nextTick                | 提交后读取 DOM                       | 没有适用于所有目的的直接替代             |
| v-model                 | value / onChange                     | 都要明确数据所有权                       |
| 插槽                    | children / 内容 props / render props | 具名内容与传出内部数据是不同接口         |
| provide / inject        | Context                              | 跨层传值能力相似，更新机制不同           |
| Composable              | 自定义 Hook                          | React Hook 随渲染执行，遵守调用顺序      |
| Pinia                   | Zustand                              | 原地修改不能迁移成 Zustand 更新方式      |
| Scoped CSS              | CSS Modules 等                       | 属性选择器与局部类名机制不同             |
