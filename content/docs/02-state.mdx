## 购物车：总价应该是状态吗

数量是输入，总价可以推导。若同时保存 total，就要维护两份数据的一致性，容易在删除或批量更新时遗漏。

<CodeBlockTabs groupId="framework" defaultValue="react">
<CodeBlockTabsList><CodeBlockTabsTrigger value="vue">Vue</CodeBlockTabsTrigger><CodeBlockTabsTrigger value="react">React</CodeBlockTabsTrigger></CodeBlockTabsList>
<CodeBlockTab value="vue">

```vue title="Cart.vue"
<script setup lang="ts">
import { computed, ref } from 'vue'
const items = ref([
  { id: 1, name: '笔记本', price: 20, quantity: 1 },
  { id: 2, name: '钢笔', price: 10, quantity: 2 },
])
const total = computed(() => items.value.reduce((sum, item) => sum + item.price * item.quantity, 0))
</script>
<template>
  <div v-for="item in items" :key="item.id">
    {{ item.name }}<input v-model.number="item.quantity" type="number" min="0" max="99" />
    <button @click="items = items.filter(row => row.id !== item.id)">移除</button>
  </div>
  <p>总价：¥{{ total }}</p>
</template>
```

## 对象、数组与不可变更新

Vue reactive 是代理，修改被追踪的属性可触发相关更新；ref 包含的对象默认也做深层响应式转换。React 对象和数组的更新应创建新引用，setter 以 Object.is 判断相同状态时可能跳过更新。

```ts title="同一需求的更新形状"
// Vue：profile 是 reactive({ name: '小林', tags: ['Vue'] })
profile.name = '小周'
profile.tags.push('React')
// React：profile 来自 useState
setProfile(previous => ({ ...previous, name: '小周' }))
setProfile(previous => ({ ...previous, tags: [...previous.tags, 'React'] }))
```

展开运算符只是浅复制。修改嵌套字段时要复制从根到修改字段的各层；数组用 map/filter 等返回新数组的方法。不要先 sort/splice 原状态再把同一个引用传回。

## 不参与界面的可变值

Vue setup 通常每实例执行一次，定时器 ID 可放在 setup 作用域普通变量；React 函数组件随渲染再次运行，函数内普通局部变量不能跨渲染保存。useRef 在同一实例中保留容器，改 current 不请求渲染。

<include lang="tsx" meta='title="对象更新与定时器 ID"'>../../components/examples/basics.tsx#reference</include>

<Demo id="E04" title="对象更新与可变引用">多次点“仅修改 ref”，界面不变；点“读取 ref 并展示”，把读取结果保存到状态。安排任务后点取消，使用保存的 timer ID 清理。</Demo>

```vue title="Vue 定时器与引用"
<script setup lang="ts">
import { onUnmounted, reactive, toRefs } from 'vue'
const profile = reactive({ name: '小林', tags: ['Vue'] })
const { name } = toRefs(profile)
let timer: ReturnType<typeof setTimeout> | undefined
function schedule() {
  clearTimeout(timer)
  timer = setTimeout(() => { name.value = '小周' }, 1000)
}
onUnmounted(() => clearTimeout(timer))
</script>
<template><button @click="schedule">{{ name }}</button></template>
```

需要显示的值放 state；不要在渲染期间读写 ref 绕过数据流。ref 适合在事件或 Effect 中保存 DOM、ID 和最新已提交值。

## 解构与复杂状态转换

Vue `const { name } = reactiveObject` 对普通基本类型属性取得当前值，丢失后续代理属性访问链；用 toRef/toRefs 保持连接。对象属性本身是代理的情况需分别分析。**Vue 3.5+ defineProps 解构**由编译器在同一 script setup 中改写，不能说“所有解构都丢失响应式”；传给 watch 仍用 getter：`watch(() => name, callback)`。

React 每次解构 useState 结果得到该次快照。多个字段间有约束时，可用 reducer 集中转换：

```tsx title="集中转换"
import { useReducer } from 'react'
type State = { quantity: number; coupon: boolean }
type Action = { type: 'add' } | { type: 'reset' }
function reducer(state: State, action: Action): State {
  switch (action.type) {
    case 'add': return { ...state, quantity: state.quantity + 1 }
    case 'reset': return { quantity: 0, coupon: false }
  }
}
function CartActions() {
  const [state, dispatch] = useReducer(reducer, { quantity: 0, coupon: false })
  return <button onClick={() => dispatch({ type: 'add' })}>{state.quantity}</button>
}
```

Vue 可在方法或组合式函数中集中相同规则，不必为了对称增加 reducer。
